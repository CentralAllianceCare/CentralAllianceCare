# CentralAllianceCare.com.au — Platform Requirements

## User Types

### Business Providers (Healthcare — NDIS & Aged Care)
- Create profiles (Facebook-style)
- Post, comment, like, share
- Chat (video & audio)
- Live bookings & appointments
- Timetable: service availability + separate timetable for interviews/video calls
- Education portals (optional)

### Workers (AIN, EN, RN, Coordinator, Fund Manager, Quality Control, etc.)
- Profile showcasing:
  - Qualifications
  - References (live — bookable via timetable system)
  - Experience
  - Interest, career goals
  - Expected salary
  - Transport, license
- Social: post, share, likes, chat (video & audio)
- Timetable (availability)
- Compliance documents:
  - Children check
  - NDIS registration
  - First aid (with expiry date)
  - Vaccination (date recorded, requested ONLY after successful hiring, not before)

## Phases

### Phase 1 — Presentable Static Site (NOW)
- Clean up existing HTML template
- Professional branding, content, imagery
- Mobile responsive
- Core pages: Home, About, Services, Contact, Register interest

### Phase 2 — Auth + Profiles
- User registration/login (providers + workers)
- Profile creation (both types)
- Dashboard per user type
- Backend API + database

### Phase 3 — Social Features
- Posts, comments, likes, shares
- News feed
- Notifications

### Phase 4 — Bookings & Timetables
- Provider service timetable
- Interview/video call timetable
- Worker availability timetable
- Live reference booking system

### Phase 5 — Communication
- Real-time chat (text)
- Video & audio calls
- Appointment reminders

### Phase 6 — Education & Compliance
- Education portals for providers
- Worker document management (certs, expiry tracking)
- Compliance dashboard
